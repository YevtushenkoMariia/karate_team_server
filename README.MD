Це створить SQL-міграцію в prisma/migrations/, застосує її до Neon і оновить клієнт.
Важливо: якщо схему отримали через db pull (introspection), а не з нуля — перший migrate dev може вимагати "baseline" міграції, бо Prisma ще не знає історії змін бази. Якщо матимете таку помилку — скажіть, покажу як зробити baseline.
